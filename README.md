# Implementación de Lista Ligada en Java

Proyecto académico sobre la estructura de datos *Singly Linked List* para la materia de Estructura de Datos.

## Contenido del Repositorio
* `LinkedList.java`: Clase que contiene la estructura del nodo y todos los métodos de manipulación de la lista (inserción, eliminación, búsqueda, reversión y detección de ciclos).
* `Main.java`: Clase de pruebas unitarias que ejecuta y verifica cada método programado.

## Métodos Implementados
- Inserción: `append`, `prepend`, `insert`
- Eliminación: `removeLast`, `removeFirst`, `remove`
- Lectura / Utilidades: `getNode`, `setNode`, `medio`, `ciclo`, `reverse`, `printList`
